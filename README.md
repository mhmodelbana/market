# 🛒 سوبر ماركت أونلاين

موقع سوبر ماركت حماصه للطلبات عبر واتساب مع لوحة تحكم وإدارة المنتجات والأقسام ومواعيد العمل.

## حالة النسخة

النسخة الحالية تتضمن نموذج **إضافة منتج جديد** في لوحة الإدارة، ويحتوي على:
- اسم المنتج
- السعر بالجنيه
- الوحدة
- القسم
- رابط الصورة
- عليه خصم؟
- السعر القديم
- إضافة المنتج

آخر مزامنة مع نسخة لوحة الإدارة الحالية: 2026-09-15.
